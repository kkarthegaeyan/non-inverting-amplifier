1. Introduction

A non-inverting summing amplifier adds several input voltages and produces an output that is in phase with them. The inputs connect through resistors to the non-inverting (+) terminal; a feedback network Rf and Rg sets the gain. With equal input resistors, the + terminal sees the average of the inputs, and the amplifier multiplies it by 1 + Rf/Rg.

Why it matters: adders are the core of analog computers, mixers, DAC output stages and sensor-signal conditioning.

Prerequisites: ideal op-amp rules (infinite input resistance, virtual short V+ = V−), superposition, voltage divider, KCL.

3. Working principle

  1. Averaging. No current enters the ideal + terminal, so the three sources and resistors form a node: V+ = (V1+V2+V3)/3 when R1=R2=R3.
  2. Virtual short. Negative feedback forces V− = V+.
  3. Gain. Rf and Rg divide Vo: V− = VoRg/(Rf+Rg), so Vo = (1+Rf/Rg)V+.
  4. Signal flow: inputs → R1–R3 → + terminal → amplifier → output → Rf/Rg divider → − terminal.

DC vs AC: the same result holds for AC inputs until the op-amp's gain-bandwidth limit (bandwidth ≈ GBW/ACL) is reached.

Advantages: positive output, high input resistance at the + terminal. Limitations: sources load each other through the resistor network; the gain is fixed for all inputs; output saturates at the rails.

Misconceptions: (1) The output is not automatically the sum – it is (1+Rf/Rg) × average, so a sum needs Rf/Rg = n−1 for n equal inputs. (2) Virtual short applies only in the linear region, not in saturation.

Comparison with theory

Ideal result with the lower R4 as feedback: V+ = 2 V, so Vo = (1 + 10k/1k)(2 V) = 22 V, which is beyond the +12 V rail. The ideal output would therefore saturate near +12 V, not read 6.0 V.

Discrepancy supported by the image: the upper R4 appears to run from the output to the + node (node 6). Including it, the ideal linear solution is Vo = 33 V (see Problem 3), which also saturates. A 6.0 V reading matches neither case. Note that 6.0 V equals V1+V2+V3, which would need Rf/Rg = 2 (for example Rf = 2 kΩ). Also, the 2.00 mA probe current does not match 6 V/11 kΩ ≈ 0.55 mA through the lower R4 + R5 path.
Suggested checks: confirm the wire from node 6 to the output is intended; set R4 to 2 kΩ if the sum is the goal; check the op-amp model's output limits; re-run the DC operating point. I cannot tell the exact cause from the image alone.

5. Equations and derivations

(a) + terminal (equal R, n inputs, no feedback to +): by KCL with I+ = 0:

(V1−V+)/R + (V2−V+)/R + (V3−V+)/R = 0 ⇒ V+ = (V1+V2+V3)/3

(b) Output: V− = VoRg/(Rf+Rg) = V+

Vo = (1 + Rf/Rg)·(V1+V2+V3)/3 [V; R in Ω]

(c) Pure sum: choose 1 + Rf/Rg = 3, i.e. Rf = 2Rg, giving Vo = V1+V2+V3. In general Rf = (n−1)Rg.

(d) Unequal resistors: V+ = Σ(Vi/Ri) / Σ(1/Ri). Limiting cases: Rg → ∞ gives gain 1 (follower); Rf = 0 gives gain 1.

(e) Decibels and bandwidth: AdB = 20 log10|ACL| (11 → 20.83 dB); f−3dB ≈ GBW/ACL. Saturation: |Vo| ≤ ≈ Vsupply (real op-amps a little less).

(f) Screenshot's upper R4 as extra feedback (Rp = 10 kΩ to + node): (ΣVi)/R + Vo/Rp = V+(3/R + 1/Rp); with V+ = Vo/11 this gives Vo = 33 V (ideal), saturating.

6. Solved numerical problems

Problem 1 (easy)

Two sources 1 V and 3 V via equal resistors, Rf = Rg = 10 kΩ. Find Vo.
V+ = (1+3)/2 = 2 V; gain = 1+10/10 = 2; Vo = 4 V (= V1+V2, a sum for n = 2).

Problem 2 (moderate)

For the 1 V, 2 V, 3 V inputs, R = 1 kΩ and Rg = 1 kΩ, find Rf for Vo = 6 V.
V+ = 2 V; need gain 3 = 1 + Rf/1 kΩ ⇒ Rf = 2 kΩ. Interpretation: with Rf = 10 kΩ the output would be 22 V and clip.

Problem 3 (GATE-style, difficult)

The circuit of Fig. 2 (R = 1 kΩ ×3, Rp = 10 kΩ from output to + node, Rf = 10 kΩ, Rg = 1 kΩ, ideal op-amp, no saturation). Find Vo.
KCL at +: 6 + 0.1Vo = 3.1V+ (V, mA, kΩ). Virtual short: V+ = Vo/11. So 6 + 0.1Vo = 0.2818Vo ⇒ Vo = 33 V. Net feedback is negative because the − path fraction (1/11 = 0.091) exceeds the + path fraction (0.1/3.1 = 0.032). Interpretation: with ±12 V rails the real output saturates near +12 V.
Shortcut: for equal R the + node is always the average of inputs.

9. Applications and industry relevance

  • Audio mixers: combine channels (usually inverting summers, but non-inverting where high input impedance is needed).
  • DAC output stages: weighted sums of binary inputs.
  • Sensor offset and averaging: average several temperature or strain signals.
  • Analog computers and PID controllers: add error terms.

Design considerations: resistor tolerance (1% resistors set gain accuracy), output swing versus supply, op-amp bandwidth and offset. Testing challenges: source loading, saturation hiding errors, wiring mistakes in simulation (as in Section 4). Roles: analog design, hardware validation, electronics R&D.
